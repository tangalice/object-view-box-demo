# CSS object-view-box demo

A bakery-themed website demonstrating CSS `object-view-box`, including a sliding banner, hover zooms, interactive image and video crops, cursor magnification, and focus hopping.

Open `index.html` in a browser that supports `object-view-box` to try the demos.

The [internship presentation](InternPresentation.key) was created and presented around the halfway point of my internship. It reflects work in progress, so some implementation details—particularly video support—no longer describe the final implementation.
